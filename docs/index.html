PYTHON SERVICE & TASK MANAGER

Chronodux documentation

A lightweight Python service manager for orchestrating threads, background tasks, and code execution lifecycles.

Get started → View on PyPI ↗

Version 0.1.0 · Python ≥ 3.10 · Alpha · Standard-library runtime

Overview

Chronodux provides a unified interface for managing Python threads and concurrent execution through two backends:

Threading

Direct execution using Python's threading.Thread.

Concurrent

Managed execution using concurrent.futures.ThreadPoolExecutor.

Task lifecycle

Track, join, cooperatively cancel, and retrieve task results.

Services & health

Manage reusable services and inspect execution metrics.

Features

  • Dual execution backends and task management.
  • Task context for cooperative termination.
  • Result handling and execution exceptions.
  • Reusable service lifecycle management.
  • Concurrency utilities, execution metrics, and health monitoring.
  • Manager shutdown and context manager support.
  • Python standard library runtime with no external runtime dependencies.

Installation

Requires Python 3.10 or newer.

python -m pip install chronodux
python -m pip show chronodux

Quick start

from chronodux import Chronodux

def sample_task():
    print("Running managed task...")

manager = Chronodux()
task = manager.start(sample_task)
manager.join(task.id)
print(manager.status(task.id))
manager.shutdown()

Execution backends

Threading

from chronodux import Chronodux

manager = Chronodux(backend="threading")

def worker():
    print("Executing through threading")

task = manager.start(worker)
manager.join(task.id)
manager.shutdown()

Concurrent

The concurrent backend uses ThreadPoolExecutor. max_workers controls the maximum worker-thread count.

from chronodux import Chronodux

manager = Chronodux(backend="concurrent", max_workers=4)

def worker():
    return "Concurrent execution completed"

task = manager.start(worker)
print(manager.result(task.id))
manager.shutdown()

Task management

Start a task

task = manager.start(target_function, "argument", name="MyTask")

task = manager.start(
    target_function,
    backend="threading",
    name="MyTask",
    daemon=False
)
ParameterDescription
targetCallable to execute
*argsPositional arguments
backendExecution backend override
nameTask name
daemonDaemon setting for threading tasks
pass_contextInject a TaskContext
**kwargsKeyword arguments

Retrieve, list, and inspect

task = manager.get(task.id)
print(task.id, task.name, task.status, task.backend)

tasks = manager.list_tasks()
for task in tasks:
    print(task.name, task.status)

running_tasks = manager.list_tasks(status="running")
print(manager.status(task.id))
print(manager.status())

Statuses: pending, running, completed, failed, cancelled.

Results and waiting

result = manager.result(task.id)
result = manager.result(task.id, timeout=10)
manager.join(task.id)
manager.join()
manager.join(timeout=10)

result() returns the task result and propagates execution exceptions.

Stop, cancel, and remove

manager.stop(task.id)
manager.cancel(task.id)  # alias for stop()
manager.remove(task.id)  # remove a completed task
manager.clear()          # clear completed tasks
Important: Python threads cannot be forcibly terminated safely. Running tasks must cooperate with termination requests using TaskContext.

Task context & cooperative cancellation

from chronodux import Chronodux

manager = Chronodux()

def background_worker(context):
    while not context.stop_requested:
        print("Worker is running...")
        if context.wait(1):
            break
    print("Worker stopped.")

task = manager.start(background_worker, pass_context=True)
manager.stop(task.id)
manager.join(task.id)
MemberDescription
id, nameAssociated task identity
stop_requestedChecks whether termination was requested
stop()Requests cooperative termination
wait(timeout)Waits for a termination request
raise_if_stopped()Raises InterruptedError if termination was requested

Service management

def background_service():
    print("Service started")

manager.register_service("example-service", background_service)
task = manager.start_service("example-service")
task = manager.start_service("example-service", backend="concurrent")
manager.stop_service("example-service")
manager.restart_service("example-service")
manager.unregister_service("example-service")
manager.unregister_service("example-service", stop=True)
services = manager.list_services()

The returned dictionary contains service names, associated task IDs, and service execution statuses.

Concurrency utilities

task = manager.submit(background_function, "argument")
task = manager.run_thread(background_function, "argument")
done, not_done = manager.wait()
done, not_done = manager.wait(timeout=5, return_when="ALL_COMPLETED")

return_when accepts ALL_COMPLETED, FIRST_COMPLETED, and FIRST_EXCEPTION.

Monitoring & metrics

metrics = manager.metrics()
print(metrics)

health = manager.health()
print(health)

Metrics include task totals and counts by execution state. Health information includes manager name, package version, default backend, manager active state, and execution metrics.

Example metrics structure:

{
    "total": 5,
    "pending": 0,
    "running": 2,
    "completed": 2,
    "failed": 1,
    "cancelled": 0
}

Manager lifecycle

Shutdown

manager.shutdown()
manager.shutdown(wait=True, cancel_futures=False)

wait waits for managed execution to finish. cancel_futures attempts to cancel pending executor futures. Running tasks receive cooperative termination requests; running threads cannot be forcibly terminated.

Context manager

from chronodux import Chronodux

with Chronodux() as manager:
    task = manager.start(lambda: print("Managed execution"))
    manager.join(task.id)

The manager automatically shuts down when the context exits.
